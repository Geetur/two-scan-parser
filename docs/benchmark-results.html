What the measurements support

Large mixed streams show a repeatable wall-time advantage on this machine. Small fixed expressions still favor the stack. Varied small batches can be competitive, but do not show a consistent general advantage. Independent numerical bindings are a synthetic workload.

Variability and allocation

The virtualized host shows substantial timing variability. The 31-sample confirmation retained every sample. Fresh-allocation results include workspace and output allocation, parse, and scratch release; returned graph release is outside the timer. Reuse and allocation are separate experiments.

Experiment definitions
  • Fixed eight states: the language's same eight-state table for every family; no per-input state pruning.
  • Used states: the distinct right binding powers in that stream. Encoding is excluded; it is not free if a deployment must perform it.
  • Small latency: 512 repeated calls to the same expression per sample, reported per call. Buffers are reused. This favors branch prediction.
  • Varied batches: 1,024 different expressions per batch. Each worker reuses its own workspace. All three algorithms can parallelize independent groups.
  • Fresh allocation: output/workspace allocation, parse, scratch release. Input preparation and returned graph release are excluded.
  • Confirmation: an additional 31-sample run on the two large mixed families; original measurements are retained.
  • Preliminary tuning: 7 samples per configuration at spin settings 0 and 1000. These are separate from the final run.
Correctness and machine details

8,133 input groups and 66,744 native backend/thread/configuration checks passed against an independent oracle, comparing pop, witness, parent/left/right, and root. The same suite passed UBSan and AddressSanitizer/UBSan (leak detection disabled for the environment). Python checks: 10,175 normalized groups, 10,684 native calls, plus 1,000 programs (384 accepted, 616 rejected). Concurrent-call checks: 24 calls from four callers, two requested native workers each; this was not a race-detector run.

Native release flags include C++17, -O3 -march=native -fopenmp, and disabled automatic loop/SLP vectorization; explicit SIMD intrinsics remain enabled. Stack and scans use the same flags. No LTO. Final settings: OMP_WAIT_POLICY=PASSIVE, OMP_PROC_BIND=TRUE, GOMP_SPINCOUNT=0. Actual worker counts, source hashes, commands, and machine metadata are included in the JSON download.

This self-contained report embeds all data and uses no external scripts or network requests. The reference and optimized modes are compiled together for same-machine comparisons. Earlier AMD measurements are not mixed with these Intel results.
